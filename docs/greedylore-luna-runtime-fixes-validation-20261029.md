## Separate host fault injection

A separate injection used an actual scratch path returned by one of the independent runs: rejection left execution count 2 before and after, request IDs unchanged and the poison marker absent. These are host tests, not Luna decisions. A literal pre-injection budget snapshot was not captured for the first two checks.

An isolated invocation of production `analyze()` with an explicit `/workspace/results/output.json` citation was rejected before Analysis publication. This negative control is separate from the Luna Analyzer, which did not submit that bad citation; the run does not claim an observed model citation rejection and correction cycle. A further separate host fixture used actual public notes and a real Git candidate: the same `analyze()` context rejected the temporary citation with no public Analysis, then accepted a corrected missing-evidence description and published version 1. Its manifest seal verified; recovery returned that version without another runner call or extra Analysis version. This is a host-injected rejection-and-correction cycle, not model behavior.
